# Критерии приёмки MOBILAINISHA 2.0
- [ ] Существующая рабочая версия не изменилась.
- [ ] Полная клиентская витрина сохранена: главная, каталог, карточки, поиск, корзина, заказы, магазины, ремонт, гарантия, поддержка, профиль.
- [ ] Вход по подтверждённому телефону, а не по произвольно введённому номеру.
- [ ] Активный сотрудник после входа сразу видит рабочую зону, клиент — клиентскую, владелец — свою.
- [ ] Сотрудник переключается в клиентскую зону и обратно без повторной авторизации.
- [ ] Сервер отклоняет доступ к чужому магазину и отозванной роли.
- [ ] Покупка с телефона A видна сотруднику на телефоне B и владельцу на C.
- [ ] Ремонт с A проходит приёмку/мастера на B с тем же ID, клиент видит статусы.
- [ ] Заказы, ремонты и остатки не дублируются при повторных запросах.
- [ ] Документы A4 сверены с оригинальными образцами.
- [ ] Законное размещение персональных данных РФ, авторизация, аудит, резервные копии.
- [ ] Реальная оплата/чеки/1С только после отдельной интеграции и тестов.
- [ ] Safari iPhone, Android, PWA, печать, навигация назад, регрессия всех разделов.
**Ни один из этих пунктов не объявляется пройденным без фактического испытания.**
